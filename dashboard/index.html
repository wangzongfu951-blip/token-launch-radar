How the value is built

Implied value = TVL × category multiple × growth × maturity × new-protocol × breadth. The multiple is the median market-cap / TVL of the live-token protocols in the same category — the market's own price for a unit of TVL — falling back to the global median where a category has fewer than three live protocols, and clamped to 0.05–0.50. Growth uses the 7-day TVL change clamped to −50…+150%. Maturity rises with the days since listing, to 1.00 at three years; a protocol under 90 days old is discounted 20% as unproven. Breadth adds 4% per extra chain, to five. No name is ever special-cased: the same function scores every row.
