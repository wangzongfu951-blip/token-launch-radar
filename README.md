Token Launch Radar ranks the pre-token protocols in a sealed DefiLlama snapshot by the implied value of a token they have not launched: TVL times the median market-cap/TVL of live protocols in the same category, adjusted for seven-day growth, age and chain breadth — with a concrete farm plan for every row and a static dashboard to read it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
